# tuatara.ca

Source of https://tuatara.ca/, published with GitHub Pages.

- `site/` is what gets published: the GitHub Actions workflow in `.github/workflows/pages.yml` uploads this folder on every push to `main`.
- The Transport Fever 3 mod pages live in `site/personal/shawn/gaming/tf3/` (a placeholder for now).
- The custom domain is set in the repository's Pages settings, so there is no `CNAME` file.
