Installing the mods

The mods come from mod.io through the game's own Mod Hub. Each save picks its own mods and settings.

Get a mod

  1. In the game's main menu, open the Mod Hub.
  2. Search for the mod by name (or for tuatara) and subscribe. The game downloads it.

Mods marked Coming soon aren't on mod.io yet.

Turn it on for a save

  1. Start a new game, or in Load Game pick a save, and open its Mods.
  2. Switch the mod on. Each save keeps its own list.

Choose its features

Every feature of a mod has its own switch, and most are on by default.

  1. In the same mod list, click the gear next to the mod.
  2. Under Settings, set each feature Off or On.

Off turns a feature off completely: its buttons and columns are gone and it does no work in the background.

Report a problem

  1. Turn the mod's Logging setting on (it is off by default).
  2. Play until the problem shows again, then quit the game.
  3. Find the game log: Steam\userdata\<your Steam id>\3493540\local\crash_dump\stdout.txt.
  4. Describe what happened in the comments on the mod's mod.io page, and mention the log.
